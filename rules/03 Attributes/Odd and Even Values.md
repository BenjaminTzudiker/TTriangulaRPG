# Odd and Even Values

Several attributes give a bonus at each **odd** value (1, 3 and 5) and a different bonus at each **even** value (2, 4 and 6). See the [[Quick Reference#Attribute Bonus Table|Attribute Bonus Table]] in the Quick Reference.
